- Filtros

2. Abra index.html.
3. Crie sua conta.
4. Publique e avalie receitas.

IMPORTANTE
Esta versão é uma demonstração 100% front-end. Usuários, senhas, receitas, favoritos e avaliações são armazenados no localStorage do navegador. Não use isso como sistema de autenticação de um site público. Em produção, use um backend, banco de dados, HTTPS e armazenamento seguro de senhas com hash.

IMAGENS
A versão usa capas em emoji para funcionar sem depender de arquivos externos. Para produção, você pode substituir as capas por imagens armazenadas em um servidor/CDN.
